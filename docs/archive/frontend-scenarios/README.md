# Archived scenario interface

This directory preserves the illustrative HealthTech / Marketplace interface and its integration variants from Git commit `552653f`. The human had rolled that interface back and retained the supplied Ingenium logo. The active `frontend/` source now matches that approved logo-only interface, recorded by deployment `20261024T203754Z-6ff0a06c537f`.

The archived files include scenario components, example claims, tests, supplied photographs and the prior versions of files that integrated those scenarios. Their original relative paths are retained under `frontend/`. This is a reference snapshot rather than a standalone application; shared components remain in the main repository and the complete historical source remains in Git.

These examples are excluded from the current frontend build and tests. They are not real company evidence or instructions to restore the reverted UI. [The manifest](manifest.json) records their original paths and SHA-256 values. [Photograph provenance](frontend/public/images/projects/README.md) is retained with the archived files.
