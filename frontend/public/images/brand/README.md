# Ingenium brand artwork

`ingenium-logo.png` is the original logo supplied by the human on 2026-10-24. Its bytes are preserved. `src/Brand.tsx` displays the symbol and wordmark through SVG viewports and a white-background filter; no replacement lettering or generated logo is used. Dark landing surfaces use a white wordmark variant through CSS. The favicon is a simplified native SVG rendition for small browser tabs.

`BrandLogo` is used in landing navigation/footer, the platform sidebar and report header. `BrandMark` replaces temporary AI/brand sparkles, wand and lightning icons through the shared Icon component. Search, folder, file, navigation and other functional icons retain their meanings.
