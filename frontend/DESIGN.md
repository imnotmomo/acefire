# Acefire visual direction

The user's four supplied reference images are the current design authority.

1. Projects: a white sidebar, pale gray application canvas, quiet blue accents,
   white summary tiles, and three-column project cards with architectural covers.
   Covers are original local SVG artwork; the preview needs no image host.
2. Dashboard: a black-and-white chart, a large central financial figure, restrained
   controls, smaller calculation summaries, and a dark contextual assistant dock.
3. Metric lineage: lavender canvas, purple column headers, expanded source cards,
   curved directed edges into a formula/review node, then a result. Nodes can be
   selected and the graph can be zoomed and horizontally scrolled.
4. Report review: neutral document surface, a serif reading column, adjacent
   findings cards, a dark featured finding, and an activity rail. No invented
   confidence percentages or automated investment decisions.

Tokens: canvas #f6f6f9, white #ffffff, ink #292b33, muted #687287,
blue #7188ed, purple #8875e8, document canvas #f2f0ed.
Interface typography: native Segoe UI; document typography: Georgia.
All alignment follows the work: left-aligned lists and editing controls, centered
headline financial value, source-to-result lineage flowing from left to right.

The initial forest theme was superseded by these references before visual QA.
The skill search returned marketing/OLED suggestions twice; these did not fit
and were discarded. Accessibility and keyboard guidance were used as a fallback.

Product contract: Projects > Dashboard / Report / Data room. Report follows
Build > Review > Export. Chat is available across the project. This is a local
browser workspace with saved Enfuce evidence, not a live extraction or AI service.
Missing evidence stays missing. Project state is isolated and persisted locally.
